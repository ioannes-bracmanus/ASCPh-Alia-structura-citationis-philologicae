Estas son unas normas básicas o "esqueleto" de sistema bibliográfico de citado y composición de bibliografías, compuesto íntegramente para LaTeX, pero que puede usarse, siguiendo la estructura en el manual, en otros programas como Microsoft Word. El documento se compuso con la fuente [AltStandard](https://github.com/Ioannes-Brclds/AltStandard.git). El código en los archivos .bbx, .blx, .cbx y .dbx fue producido a través de IA (Google Gemini), a partir de indicaciones específicas del diseño técnico del sistema de citación. Se puede cambiar la estructura como se considere necesario y hacer un "fork" con modificaciones, con la condición de cambiar el nombre del sistema (también se puede cambiar la licencia, siempre y cuando se respete que sea "código abierto"). Si tiene alguna sugerencia, compártala.
